# 競輪予想AI（仮想購入・回収率の自動記録）

過去のレース結果から**各選手の1着確率**を出し、**予想どおりに買ったら回収率は何%だったか**を毎日 Excel に記録するツールです。
**お金は一切使いません**（すべて仮想購入）。

> ⚠️ 競輪の払戻率は約75%です。適当に買い続けると回収率は75%前後に近づきます。
> このツールの役目は「AIがそれを超えられるのか」を、**運のブレも含めて正直に測ること**です。

## 今日やること（Windows、初めての人向け）

### 1. Python を入れる（5分）
1. https://www.python.org/downloads/ から **Python 3.12** をダウンロード
2. インストール画面の一番下 **「Add python.exe to PATH」にチェック** → Install Now

### 2. このフォルダを PC に置く
GitHub の「Code → Download ZIP」で落として解凍し、たとえば `C:\keirin_ai` に置きます。
（パスに日本語や空白が無い場所が無難です）

### 3. セットアップ（ダブルクリックだけ）
`windows\setup.bat` をダブルクリック → 「Setup finished」と出たらOK。

### 4. お試し（架空データ）
`windows\run_demo.bat` をダブルクリック。1分ほどで Excel が開きます。
- 架空の選手・架空のレースで「学習 → 60日分の過去検証 → Excel」まで動きます。
- **数字は架空の世界のもの**です。本物の成績とは関係ありません。動作確認用です。

### 5. 毎日の自動実行を登録
`windows\register_tasks.bat` をダブルクリック。
- `predict`：8:00〜23:30 の間、20分ごとに「もうすぐ発走するレース」を予想して仮想購入
- `daily`：毎日 23:50 に 結果取得 → 精算 → AI再学習 → Excel 更新
- **PC の電源が入っていて、サインインしている時間しか動きません。**
- やめるときは `windows\unregister_tasks.bat`。

Excel は `output\回収率レポート.xlsx` に毎日上書きされます（開いたままだと別名で保存されます）。

## Excel の見方

| シート | 中身 |
|---|---|
| サマリー | 戦略×券種ごとの 点数・的中率・回収率・**95%区間**・判定 |
| 日別 | 日ごとの回収率と累計回収率（100%以上=緑、未満=赤） |
| 累計回収率グラフ | 累計回収率の推移 |
| 最新の予想 | 直近のレースの各選手のAI勝率と順位 |
| 購入履歴 | 仮想購入1点ずつの記録（判断時刻・オッズ・結果） |
| AIの重み | AIが何を重視しているか（プラス=勝ちやすくなる要素） |
| 説明 | 用語の説明 |

### 3つの買い方を並べて記録します
- **AI本命**：AIの確率が一番高い組み合わせを各券種1点。→ ご依頼の「予想どおりに買ったときの回収率」
- **AI期待値**：「AIの確率 × オッズ」が 1.2 以上の組み合わせだけ買う
- **人気1位**：一番人気を買い続けた場合。**AIがこれに勝てないなら、AIを使う意味は薄い**という物差し

### 「判定」の読み方（いちばん大事）
- **◎**：95%区間の下限が100%超え → 運だけでは説明しにくいプラス
- **△**：区間が100%をまたぐ → **まだ運の範囲。勝っているとは言えない**
- **×**：上限が100%未満 → 負けている
- 例：デモの3連複では、約2,000点買っても区間が「74%〜101%」くらいの幅になります。**数百点の記録で「勝てる」と判断するのは早すぎる**ということです。

## AI の中身（ざっくり）

- **モデル**：条件付きロジット（Plackett-Luce）。香港競馬で成功した Bill Benter の手法の土台と同じ形です。
  各選手に「強さスコア」をつけ、レース内で合計100%になるように1着確率へ変換します。1〜3着の順番まで学習に使います。
- **使っている情報**：競走得点、級班、脚質（逃・両・追）、ライン（先頭・番手・3番手・単騎、ラインの強さ）、地元、年齢、直近10走の成績
- **2車複・2車単・3連複の確率**：1着確率からハービル式で計算
- **カンニング防止**：
  - 直近成績は「そのレースより前」だけから計算
  - 過去検証は「その日より前のデータだけで学習 → その日を予想」を繰り返す
  - 判断には「判断した時刻より前に取ったオッズ」しか使わない（締切後の確定オッズは使わない）
  - 仮想購入は一度記録したら書き換えない

## 次にやること：データの取得元（サイト）を決める

サイト用の取得部品（`keirin/sources/` に1ファイル）を追加すれば、そのまま本番が動きます。必要なのは次の3つです。

1. **出走表**：車番・選手・級班・競走得点・脚質・**予想並び（ライン）**・発走時刻
2. **オッズ**：2車複・2車単・3連複（締切前）
3. **結果と払戻金**

部品を作るときは `keirin/sources/http.py` の取得ヘルパーを使います。
（robots.txt で禁止されたページは取りに行かない／1回ごとに3秒以上あける／確定済みの結果ページは保存して再取得しない）

サイトが決まるまでは、`templates` と同じ形の CSV を `inbox` フォルダに入れて取り込めます（`config.toml` の `name = "csv"`）。

### CSV で過去データを入れて検証する場合
```
.venv\Scripts\python -m keirin import-csv
.venv\Scripts\python -m keirin backtest --from 2026-01-01 --to 2026-06-30
```
締切前オッズが無いデータでは「AI期待値」「人気1位」は買われません。確定オッズで判断させる `--allow-final-odds` を付けると試せますが、**実際には買えないタイミングの情報を使うので結果は甘く出ます**（Excel で「参考値」として数えています）。「AI本命」はオッズを使わないので影響を受けません。

## 初心者が見落としがちな落とし穴

1. **過去検証の数字は本番より良く出やすい**：設定を何度も変えて一番良かった結果を選ぶと、それは「たまたま」に合わせ込んだだけです。設定を決めたら、**本番（仮想購入）の記録で判断**してください。
2. **1か月プラス＝勝てる、ではない**：Excel の「判定」が △ のうちは運の範囲です。
3. **的中率が高い ≠ 儲かる**：本命ばかり当たっても、配当が安ければ回収率は75%に近づきます。
4. **オッズは締切直前まで動く**：予想に使ったオッズと最終オッズは違います。
5. **サイトに負荷をかけない**：アクセス間隔は短くしないでください（初期値3秒）。利用規約で自動取得が禁止されているサイトは使わないでください。

## コマンド一覧（上級者向け）

```
.venv\Scripts\python -m keirin demo          架空データで一通り試す
.venv\Scripts\python -m keirin predict       発走が近いレースを予想して仮想購入（--all で全部）
.venv\Scripts\python -m keirin daily         結果取得→精算→再学習→Excel
.venv\Scripts\python -m keirin backtest --from YYYY-MM-DD --to YYYY-MM-DD
.venv\Scripts\python -m keirin import-csv    inbox のCSVを取り込む
.venv\Scripts\python -m keirin train         AIの学習だけ
.venv\Scripts\python -m keirin report        Excel だけ作り直す
.venv\Scripts\python -m pytest               テスト
```

設定（買い方の基準、券種、1点の金額など）は `config.toml` で変えられます。中にコメントで説明があります。

```
  pipeline.py     取得→予想→仮想購入→精算、過去検証

  model.py        1着確率を出すAI
  combos.py       1着確率 → 2車複/2車単/3連複の確率
  strategy.py     買い方のルール
  report.py       Excel 出力
  db.py           データベース（SQLite）
  sources/        データ取得元（sample=架空, csv, ここにサイト用を追加）
windows/          ダブルクリック用の .bat
templates/        CSV の見本
tests/            自動テスト
```
